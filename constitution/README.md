# Project Constitution

This folder is the living reference for *why* and *how* this project works, as opposed to `README.md` / `CLAUDE.md`, which describe *what* it currently contains. It's not enforced by tooling — it's a shared understanding that should be kept up to date as the project evolves.

| File | Content |
|---|---|
| [mission.md](./mission.md) | Why this project exists, what "done" looks like, explicit non-goals |
| [tech-stack.md](./tech-stack.md) | The tools in play and why each one was chosen |
| [principles.md](./principles.md) | Engineering conventions specific to this repo |
| [workflow.md](./workflow.md) | Collaboration rules — branching, commits, and the human/AI push boundary |

## Amending the constitution

This is a personal learning project with a single maintainer. Update these files directly (no approval process needed) whenever a decision changes — e.g. swapping a tool, changing scope, or changing how Claude Code is allowed to operate in this repo. Prefer editing the existing file over creating a new one; keep entries short and dated only when the date matters (e.g. a superseded decision).
